## What is BetterDisplay Pro?

BetterDisplay Pro, from developer waydabber, is a powerful tool for getting the most out of any display connected to your Mac. macOS offers limited display options, especially for third-party monitors; BetterDisplay adds the resolution, scaling, brightness, and virtual-display features that are otherwise missing. BetterDisplay Pro is a native Mac app that runs on Apple silicon and Intel Macs.

## Custom resolutions and HiDPI

BetterDisplay lets you set custom resolutions and enable HiDPI (Retina-style) scaling on displays that macOS would not normally offer it for. This means sharper text and more usable screen space on external monitors, and precise control over the exact resolution each display uses, rather than being stuck with the defaults.

## Brightness and display control

BetterDisplay adds real brightness and contrast control for external monitors, including software dimming and, on supported displays, hardware control. You can adjust brightness from the menu bar or with shortcuts, sync brightness across displays, and control settings that macOS hides, giving external monitors the same easy control as the built-in screen.

## Virtual and dummy displays

BetterDisplay can create virtual displays and dummy displays. A dummy display keeps a headless Mac or a disconnected monitor session active, useful for remote access, and virtual displays add extra screen space you can use with AirPlay or screen sharing. These features enable setups that macOS does not support on its own.
